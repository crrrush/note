# 什么是数据库

1. mysql是数据库服务的客户端
2. mysql是数据库服务的服务器端
3. mysql本质：基于C（mysql） S（mysqld）模式的一种网络服务



mysql是一套提供数据存取的网络程序

数据库一般指的是，在磁盘或者内存中存储的特定结构组织的数据 -- 将来在磁盘上存储的一套数据库方案

数据库服务 -- mysqld



与普通文件对比

普通文件并没有提供非常好的数据管理能力，对于用户或者程序员来说

数据库，对数据内容存储的一套解决方案，根据字段或要求给出结果
