# 引入

在以前使用C语言时候，读者朋友们是否出现过这样的问题，写一个初始化函数，如果为这个函数设计参数传入初始化值，那么这个初始化函数的功能似乎与其他操控函数区别不是很大，而如果不设置参数，在函数内设置好初始化值，或者用设计好的宏来作为初始化值，的确解决了上一个问题，但这个初始化值的修改却又变麻烦了。得从代码层面去修改。而C++设计的缺省参数解决了这一痛点。

# 缺省参数概念

缺省函数是**声明或定义函数时**为函数的**参数指定一个缺省值**。在调用该函数时，如果没有指定实参则采用该形参的缺省值，否则使用指定的实参。

```c++
//代码演示
void func(int a = 0, int b = 1)
{
	cout << "a = " << a << endl;
	cout << "b = " << b << endl;
}

int main()
{
	func();

	return 0;
}

```

# 缺省参数分类

## 全缺省参数

```c++
void func1(int a = 0, int b = 1, int c = 2)
{
	cout << "a = " << a << endl;
	cout << "b = " << b << endl;
	cout << "c = " << c << endl;
}
```

# 注意事项

除此之外，缺省函数还需注意：

* 半缺省函数必须从右往左依次给出，不能间隔着给。（为什么，想象一下，传参的时候编译器是否能辨别你传的参数到底是给谁的？）

* 缺省函数不能在函数声明和定义中同时出现。

  ```c++
  //Function.h
  void Print(int a = 1, int b = 2, int c = 3);
  
  //Function.cpp
  void Print(int a = 1, int b = 2, int c = 3)
  {
  	cout << "a = " << a << endl;
  	cout << "b = " << b << endl;
  	cout << "c = " << c << endl;
  }
  //如果声明和定义位置同时出现缺省，并且恰巧提供的值不同，那编译器就无法判断该用哪个缺省值。
  //所以编译器就默认声明定义分离时只在声明出进行缺省声明
  ```

* 缺省值必须是常量或者全局变量

* C语言不支持（C编译器不支持）
