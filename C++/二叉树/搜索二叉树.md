# 二叉搜索树

## 概念

BST（Binary Search Tree）

**二叉搜索树又称二叉排序树，它或者是一颗空树**，或者是具有以下性质的二叉树：

* 若左子树不为空，则左子树上所有节点的值都小于根节点的值
* 若右子树不为空，则右子树上所有节点的值都小于根节点的值
* 左右子树也分别为二叉搜索树



测试用例：

```c++
{8, 3, 10, 1, 6, 14, 4, 7, 13}
```

## 删除

**删除之后还要保持这棵树是一个搜索二叉树**

思路：

1. 子树为空或只有一颗子树  ---  托孤 将子树传给父子树
2. 两颗子树都不为空  ---  找右树的最小或左数找最大

{
public:
	T _val;
	TreeNode* _left;
	TreeNode* _right;

public:
	TreeNode() :_val(0), _left(nullptr), _right(nullptr) {}

	TreeNode(const T& val, TreeNode* left = nullptr, TreeNode* right = nullptr) :_val(val), _left(left), _right(right) {}
};

			else
				cur = cur->_right;

			else

			delete cur;
		}

	bool _insertR(TreeNode*& root, const K& key)
	{
		if (root == nullptr)
		{
			root = new TreeNode(key);
			return root != nullptr;
		}

		if (root->_val < key)
			_insertR(root->_right, key);
		else if (root->_val > key)
			_insertR(root->_left, key);
		else
			return false;
	}

	bool _findR(TreeNode* root, const K& key)
	{
		if (root == nullptr) return false;

		if (root->_val < key)
			return _findR(root->_right, key);
		else if (root->_val > key)
			return _findR(root->_left, key);
		else
			return true;
	}

	bool _eraseR(TreeNode*& root, const K& key)
	{
		if (root == nullptr) return false;

		if (root->_val < key)
			return _eraseR(root->_right, key);
		else if (root->_val > key)
			return _eraseR(root->_left, key);
		else
		{
			if (root->_left != nullptr && root->_right != nullptr)
			{
				TreeNode* cur = root->_right;
				TreeNode* parent = root;
				while (cur->_left)
				{
					parent = cur;
					cur = cur->_left;
				}
				std::swap(root->_left, cur->_left);

				if (cur != root->_right)
				{
					std::swap(root->_right, cur->_right);
					parent->_left = root;
				}

				std::swap(root, cur);


				return _eraseR(root->_right, key);
			}
			else if (root->_left != nullptr && root->_right == nullptr)
			{
				TreeNode* del = root;
				root = root->_left;
				delete del;
				return true;
			}
			else if (root->_left == nullptr && root->_right != nullptr)
			{
				TreeNode* del = root;
				root = root->_right;
				delete del;
				return true;
			}
			else
			{
				TreeNode* del = root;
				root = nullptr;
				delete del;
				return true;
			}
		}
	}
};

**缺点**：大量**插入**有序的数据会造成二叉树退化成近似单叉链，会使搜索效率大大降低O(log n) -> O(n)



既然如此，就要增加对插入操作的处理，使树在插入之后尽可能保持平衡

# AVL树

* **平衡因子记录该节点左右子树高度差（-1/0/1）**

* **左右子树都是AVL树**





**引入平衡因子**  ---  用于判断树的平衡情况，如果变得不平衡时则进行调整  ---  平衡因子 = 右树高度 - 左树高度  ---  在右子树新增节点则平衡因子+1反之则-1  ---  平衡因子大于1或小于-1时进行调整

**三叉链**  ---  更新平衡因子和调整树的高度时需要访问父节点，加入指向父节点的指针，便于调整



所以建树/调整的过程中需要保持AVL树的性质，即**每一个节点左右子树高度差不超过1**，超过则调整

由于对于每一个节点，其左右子树高度差不超过1，所以AVL树非常接近平衡，也就是搜索时的时间复杂度接近O(log2 N)





## 插入

1. 找插入位置

2. 向上更新平衡因子：
   * 更新为0， 停止更新，调整结束
   * 更新为1/-1，继续往上更新
   * 更新为2/-2，说明一侧的子树已经高于另一侧两层，需要进行旋转调整
   
3. 旋转调整的两种情况

   ```c++
   // 旋转
   if (cur->_bf == 1 && parent->_bf == 2) // cur右子树高 且cur为parent右子树
   				rotateL(parent);
   else if (cur->_bf == -1 && parent->_bf == -2)// cur左子树高 且cur为parent左子树
   				rotateR(parent);
   else if (cur->_bf == 1 && parent->_bf == -2)// cur右子树高 且cur为parent左子树
   				rotateLR(parent);// rotateL(cur) rotateR(parent)
   else if (cur->_bf == -1 && parent->_bf == 2)// cur左子树高 且cur为parent右子树
   				rotateRL(parent);// rotateR(cur) rotateL(parent)
   else
   				assert(false);
   ```

        // 1.让这颗子树左右高度差不超过1
        // 2.旋转过程中继续保持是搜索树
        // 3.更新孩子节点的平衡因子
        // 4.保持这颗树的高度

			}

			while (cur)
			{
				if (cur->_kvp.first < value.first)
				{
					if (cur->_right == nullptr)
					{
						// 插入节点
						cur->_right = new Node(value);
						parent = cur;
						cur = cur->_right;
						cur->_parent = parent;
						break;
					}
					parent = cur;
					cur = cur->_right;
				}

				// 1.让这颗子树左右高度差不超过1

				// 4.保持这颗树的高度

		void rotateL(NodePtr parent)
		{
			NodePtr fp = parent->_parent;
			NodePtr rchild = parent->_right;
			NodePtr Lrchild = rchild->_left; // 右孩子的左树

			// parent节点右指向右孩子的左
			parent->_right = rchild->_left;
			if (Lrchild) Lrchild->_parent = parent;// 不为空 右孩子的左树更新其父指针

			// 右孩子的左指向父亲
			rchild->_left = parent;
			// parent节点更新其父指针
			parent->_parent = rchild;

			// fp指针指向右孩子
			if (fp && parent == fp->_left)
				fp->_left = rchild;
			else if (fp && parent == fp->_right)
				fp->_right = rchild;
			else
				_root = rchild;
			// 右孩子更新其父指针
			rchild->_parent = fp;
			
			// 更新平衡因子
			parent->_bf = rchild->_bf = 0;
		}

		void rotateR(NodePtr parent)
		{
			NodePtr fp = parent->_parent;
			NodePtr lchild = parent->_left;
			NodePtr Rlchild = lchild->_right; // 左孩子的右树

			// parent左指针指向左孩子的右树
			parent->_left = lchild->_right;
			// 左孩子不为空 更新左孩子右树的父指针
			if(Rlchild) Rlchild->_parent = parent;

			// 左孩子右指针指向parent节点
			lchild->_right = parent;
			// parent节点更新父指针
			parent->_parent = lchild;

			// fp指针指向左孩子
			if (fp && parent == fp->_left)
				fp->_left = lchild;
			else if (fp && parent == fp->_right)
				fp->_right = lchild;
			else
				_root = lchild;
			// 左孩子更新其父指针
			lchild->_parent = fp;

			// 更新平衡因子
			parent->_bf = lchild->_bf = 0;
		}

		void rotateLR(NodePtr parent)
		{
			NodePtr lchild = parent->_left;
			NodePtr rchild = lchild->_right;
			int bf = rchild->_bf;

			// 先左旋在右旋
			rotateL(lchild);
			rotateR(parent);

			// 更新平衡因子
			rchild->_bf = 0;
			if (bf == 1)
			{
				lchild->_bf = -1;
				parent->_bf = 0;
			}
			else if (bf == -1)
			{
				lchild->_bf = 0;
				parent->_bf = 1;
			}
			else if (bf == 0)
			{
				lchild->_bf = parent->_bf = 0;
			}
			else
			{
				assert(false);
			}

		}

		void rotateRL(NodePtr parent)
		{
			NodePtr rchild = parent->_right;
			NodePtr lchild = rchild->_left;
			int bf = lchild->_bf;

			// 先右旋再左旋
			rotateR(rchild);
			rotateL(parent);

			// 更新平衡因子
			lchild->_bf = 0;
			if (bf == 1)
			{
				rchild->_bf = 0;
				parent->_bf = -1;
			}
			else if (bf == -1)
			{
				rchild->_bf = 1;
				parent->_bf = 0;
			}
			else if (bf == 0)
			{
				parent->_bf = rchild->_bf = 0;
			}
			else
			{
				assert(false);
			}

		}

# 红黑树

* 每个节点不是红色就是黑色
* 根节点是黑色
* 每个叶子节点都是黑色（这里的叶子节点指的是空节点）
* **不能有连续的红色节点**
* **对于每一个节点，从该节点到其所有后代叶节点的简单路径上的黑色节点数量相同**
* 三叉链  ---  便于调整



满足以上性质后：

* 如果一条路径全是黑色节点，则该路径为最短路径
* 如果一条路径红黑色节点交替出现（没有连续黑色节点），则该路径为最长路径
* **最长路径节点个数不超过最短路径节点个数的两倍**



所以建树/调整的过程中需要保持红黑树的性质，其中最关键的是**不能有连续的红色节点**和**对于每一个节点，从该节点到其所有后代叶节点的简单路径上的黑色节点数量相同**，出现则调整



树接近平衡



## 插入

1. 找插入位置，插入红节点（插入红节点好处理）

2. 向上判断父节点是否为红节点：

   * 不是红节点，更新结束
   * 是红节点且祖父节点的另一子节点（叔叔节点）不存在或存在且为红节点，将父节点和叔叔节点更新成黑节点，祖父节点更新成红节点（祖父节点原来一定是黑节点），接着继续向上判断（含新节点的路径红节点增加且更改红黑节点顺序，其他路径黑节点数量，红节点数不变）
   * 是红节点且叔叔节点为黑节点此时需要进行旋转调整（无法在保持其他路径黑节点数量不变的情况下改变含新增节点路径的红黑节点顺序了）

3. 旋转调整

                    // 更新颜色
                    granp->_col = RED;
                    parent->_col = BLACK;

                    break;
				}
			}
			else
			{
				Node* uncle = granp->_left;

				if (nullptr != uncle && RED == uncle->_col)
				{
					uncle->_col = BLACK;
					granp->_col = RED;
					parent->_col = BLACK;

					cur = granp;
					parent = granp->_parent;
				}
				else
				{
					if (cur == parent->_right)
					{
						rotateL(granp);

						// 更新颜色
						granp->_col = RED;
						parent->_col = BLACK;

						break;
					}
					else
					{
						rotateR(parent);
						rotateL(granp);

						// 更新颜色
						granp->_col = RED;
						cur->_col = BLACK;

						break;
					}
				}
			}
		}

		// 保证根为黑
		_root->_col = BLACK;

		return std::make_pair(iterator(ret), true);
	}

		void rotateL(Node* parent)
		{
			Node* fp = parent->_parent;
			Node* rchild = parent->_right;
			Node* Lrchild = rchild->_left; // 右孩子的左树

			// parent节点右指向右孩子的左
			parent->_right = rchild->_left;
			if (Lrchild) Lrchild->_parent = parent;// 不为空 右孩子的左树更新其父指针

			// 右孩子的左指向父亲
			rchild->_left = parent;
			// parent节点更新其父指针
			parent->_parent = rchild;

			// fp指针指向右孩子
			if (fp && parent == fp->_left)
				fp->_left = rchild;
			else if (fp && parent == fp->_right)
				fp->_right = rchild;
			else
				_root = rchild;
			// 右孩子更新其父指针
			rchild->_parent = fp;
		}

		// 右旋
		void rotateR(Node* parent)
		{
			Node* fp = parent->_parent;
			Node* lchild = parent->_left;
			Node* Rlchild = lchild->_right; // 左孩子的右树

			// parent左指针指向左孩子的右树
			parent->_left = lchild->_right;
			// 左孩子不为空 更新左孩子右树的父指针
			if (Rlchild) Rlchild->_parent = parent;

			// 左孩子右指针指向parent节点
			lchild->_right = parent;
			// parent节点更新父指针
			parent->_parent = lchild;

			// fp指针指向左孩子
			if (fp && parent == fp->_left)
				fp->_left = lchild;
			else if (fp && parent == fp->_right)
				fp->_right = lchild;
			else
				_root = lchild;
			// 左孩子更新其父指针
			lchild->_parent = fp;
		}
