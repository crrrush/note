# 模板&&泛型编程

## 泛型编程

谈泛型编程这个技术之前，得先看看什么样的场景、问题或者说需求催生出了这个技术，看看以下代码。

```c++
//重载多个版本的交换函数
void Swap(int& a, int& b)
{
	int tmp = a;
	a = b;
	b = tmp;
}

void Swap(char& a, char& b)
{
	char tmp = a;
	a = b;
	b = tmp;
}


void Swap(double& a, double& b)
{
	double tmp = a;
	a = b;
	b = tmp;
}

```

两个相同类型变量交换值的交换函数，这个函数可谓是使用率极高的函数了，但是为了适**应使用场景（不同类型的交换）**，我们不得不手动重载了多个版本的交换函数。C++提供的函数重载一定程度上解决了这个问题（使用场景限制几个类型的时候）。但是问题依旧存在：

* 重载的函数仅仅只是类型不同，代码复用率比较低，而新类型出现时，又需要用户（程序员）手动增加对应的函数。
* 代码的可维护性降低了，一但一个版本的函数需要更改代码进行迭代或者出问题了，则所有的版本都需要更改，特别是如果函数本身实现逻辑较复杂时。



## 函数模板

### 语法规则及使用

#### 语法格式：

`template<tyname T1, typename T2, ..., typaname Tn>`

`返回类型 函数名(参数列表) {}`

#### 使用演示：

```c++
//示例
template<typename T1, class T2> //class 和 typename 均可，意义完全相同
void func(T1 a, T2 b)
{
	//...
}

```

**注意：`typename`和`class`是用于定义模板参数的关键字，在此处意义完全相同。**



### 函数模板的实例化

**用不同类型的参数使用函数模板时**，称为函数模板的**实例化**。模板参数实例化分为：**隐式实例化和显式实例化**：

1. **隐式实例化：让编译器根据实参推演模板参数的实际类型**
2. **显式实例化：调用时在函数名后用`<>`指定模板参数的实际类型**

```c++
template<typename T>
T Add(const T& a, const T& b)
{
	return a + b;
}


int main()
{
	int i1 = 10, i2 = 20;
	double d1 = 10.1, d2 = 20.2;

	////////////////隐式实例化

	cout << Add(i1, i2) << endl;
	cout << Add(d1, d2) << endl;

	//Add(i1, d2);// error C2672: “Add”: 未找到匹配的重载函数
	//这条语句式无法正常编译通过的，模板无法正常推导出唯一的参数类型 （i1推导出int，d2推导出double）


	//此时有两种处理方式 1.自行对参数进行强制类型转换 2.显式实例化
	cout << Add((double)i1, d2) << endl;


	/////////////////显式实例化
	cout << Add<int>(i1, d2) << endl;
	cout << Add<double>(i1, d2) << endl;
    //显式实例化时如果参数类型不匹配，编译器会尝试进行隐式类型转换，如果无法转换成功编译器会报错

	return 0;
}
```





### 匹配原则

手写已存在的VS模板生成的

1. **一个非模板函数可以和一个同名的函数模板同时存在，而且该函数模板还可以实例化为这个非模板函数**。

   ```c++
   //专门处理int类型的函数
   int Add(const int& a, const int& b)
   {
   	cout << "int" << endl;
   	return a + b;
   }
   
   //通用处理函数
   template<class T>
   T Add(const T& a, const T& b)
   {
   	cout << "template<class T>" << endl;
   	return a + b;
   }
   
   int main()
   {
   	Add(1, 2);        //匹配非模板生成的函数,有现成的函数，不需要模板去实例化一个
   	Add<int>(1, 2);	  //强制要求使用模板生成的函数
   
   
   	return 0;
   }
   ```

2. **对于非模板函数和同名函数模板，如果其他条件都相同，在调动时会优先调用非模板函数而不会从该模板产生一个实例。如果模板可以产生一个具有匹配的函数，那么将选择使用模板。**

   ```c++
   //专门处理int类型的函数
   int Add(const int& a, const int& b)
   {
   	cout << "int" << endl;
   	return a + b;
   }
   
   //通用处理函数
   template<class T1, class T2>
   T2 Add(const T1& a, const T2& b)
   {
   	cout << "template<class T1, class T2>" << endl;
   	return a + b;
   }
   
   int main()
   {
   	Add(1, 2);        // 匹配现成的非模板生成的函数
   	Add(1, 2.0);	  // 调用模板生成的更匹配参数类型的函数
   
   
   	return 0;
   }
   ```

3. **模板函数不允许自动类型转换，但普通函数可以进行自动类型转换。**

### 语法规则及使用

#### 语法规则：

```c++
//示例
template<typename T1, class T2>
class A
{
	//...
	T1 _a1;
	T2 _a2;
	//...
};
```

#### 使用演示：

```c++
//这里的线性表不是一个具体的类，而是一个类模板，是编译器根据实际调用实例化出具体类的模具
template<typename T>
class linear_list //线性表
{
public:
	linear_list();

	//...

	~linear_list();
private:
	T* _pdata;
	size_t _size;
	size_t _capacity;
};


// 注意：类模板中函数放在类外进行定义时，需要加模板参数列表
template<typename T>
linear_list<T>::linear_list()
{
	//...
}

template<typename T>
linear_list<T>::~linear_list()
{
	//...
}
```

# 模板的原理

在**编译器编译阶段**，对于模板函数，**编译器会根据传入的（或显式指定的）实参类型来推演并使用函数模板生成对应类型的函数以供调用。**对于模板类，**编译器会根据传入的实参类型推演并使用类模板生成对应的类。**
