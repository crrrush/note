# 非类型模板参数

模板参数分为**类型形参**和**非类型形参**。

**类型形参：出现在模板参数列表中，跟在`class`或者`typename`之类的参数名称。**

**非类型形参，就是用一个常量作为类（函数）模板的一个参数，在类（函数）模板中可将该参数当成常量来使用。**

```c++
template<class T, size_t N = 10>
```

**注意：**

1. **浮点数、类对象以及字符串是不允许作为非类型模板参数的。（也就是说只有整型家族的可以）**
2. **非类型的模板参数必须在编译期间就能确认结果。**
3. **模板参数可以给缺省值，非类型形参传值，类型形参传类型。**





# 模板的特化

## 概念

通常情况下，**使用模板可以实现一些与类型无关的代码，但对于一些特殊类型则可能会得到错误的结果**，所以我们期望能对某些类型进行特殊处理时，就可以使用**模板的特化**。

```c++
template<class T>
bool cmp(const T& a, const T& b)
{
	return a < b;
}



int main()
{
	Date d1(2023, 6, 1);
	Date d2(2023, 6, 2);

	cout << cmp(d1, d2) << endl; // 能得到我们期望的结果

	Date* pd1 = new Date(d1);
	Date* pd2 = new Date(d2);

	cout << cmp(pd1, pd2) << endl; 
    // 不是我们期望的处理方式，应该是比较日期的大小，而不是比较地址的大小
    // 所以得不到我们期望的结果

	return 0;
}

```



模板特化分为**函数模板特化**与**类模板特化**。

## 函数模板特化

### 语法

1. 必须要先有一个基础的函数模板。
2. 关键字`template`后面接一对空的尖括号`<>`。
3. 函数名后跟一对尖括号，尖括号中指定需要特化的类型。
4. 函数形参表：必须要和模板函数的基础参数类型完全相同，不同编译器可能会报一些奇怪的错误。

```c++
template<class T>
bool cmp(const T& a, const T& b)
{
	return a < b;
}

template<>
bool cmp<Date*>(Date* const& a, Date* const& b)
{
	return *a < *b;
}


int main()
{
	Date d1(2023, 6, 1);
	Date d2(2023, 6, 2);

	cout << cmp(d1, d2) << endl; 

	Date* pd1 = new Date(d1);
	Date* pd2 = new Date(d2);

	cout << cmp(pd1, pd2) << endl; // 调用特化的版本，而不是走模板生成
    // 当然，这里也可以使用函数重载的方式解决

	return 0;
}
```

**注意：一般情况下，如果函数模板遇到不能处理或者处理有误的类型，为了实现简单，通常都是将该函数直接给出（也就是函数重载）。**

```c++
bool cmp(const Date* const& a, const Date* const& b)
{
	return *a < *b;
}
```

这种实现简单明了，代码的可读性高，因此

对于一些参数类型复杂的函数模板，不建议使用模板特化。

## 类模板特化

### 全特化

即将模板参数列表中所有的参数都确定化。

```c++
template<class T1, class T2>
class Data
{
public:
	Data() { cout << "Data<T1, T2>\n"; }

private:
	T1 _d1;
	T2 _d2;
};

template<>
class Data<int, char>
{
public:
	Data() { cout << "Data<int, char>\n"; }

private:
	int _d1;
	char _d2;
};

int main()
{
	Data<int, int> d1;
	Data<int, char> d2;


	return 0;
}
```



### 偏特化

任何针对模板参数进一步进行条件限制设计的特化版本。比如对于以下模板类：

```c++
template<class T1, class T2>
class Data
{
public:
	Data() { cout << "Data<T1, T2>\n"; }

private:
	T1 _d1;
	T2 _d2;
};
```

有以下两种方式：

* 部分特化

  将模板参数列表中的一部分参数特化。

  ```c++
  template<class T1>
  class Data<T1, char>
  {
  public:
  	Data() { cout << "Data<T1, char>\n"; }
  
  private:
  	T1 _d1;
  	char _d2;
  };
  ```

* 参数更进一步的限制

  偏特化并不仅仅是指特化部分参数，而是针对模板参数更进一步的条件限制所设计出来的一个特化版本。

  ```c++
  template<class T1, class T2>
  class Data<T1*, T2*>
  {
  public:
  	Data() { cout << "Data<T1*, T2*>\n"; }
  
  private:
  	T1* _d1;
  	T2* _d2;
  };
  
  template<class T1, class T2>
  class Data<T1&, T2&>
  {
  public:
  	Data() { cout << "Data<T1&, T2&>\n"; }
  
  private:
  	const T1& _d1 = 1;
  	const T2& _d2 = 2;
  };
  ```



应用：对排序的比较类，`less`和`greater`的特化
