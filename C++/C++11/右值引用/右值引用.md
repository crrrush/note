# 概念（是什么）

**左值引用还是右值引用，都是给对象取别名**

**可以获取它的地址+可以对它赋值，左值可以出现赋值符号的左边，右值不能出现在赋值符号左边**

**右值可以出现在赋值符号的右边，但是不能出现出现在赋值符号的左边，右值不能取地址**

 

# 原理（为什么）

右值有哪些？

* 函数返回值（非引用）
* 表达式的结果
* 代码中的常数/字符串

这类“临时结果型”数据，通常存储在**某个专门存储临时数据的位置，这个存储位置随时都可能有新的临时数据存入，所以这种临时数据一般只提供读权限**。但也正因为此，面对需要深拷贝的数据，想要转储到可以读写的位置可能需要进行多次深拷贝拷贝，可能会造成比较大的效率损失。

右值引用提供了我们对该数据写的能力，那么我们就可以直接转移其中的数据，而不是进行深拷贝



# 作用（怎么做）

左值引用的意义：函数传参/函数传返回值  --  减少拷贝

但是能真正解决吗？返回值为string甚至vector<vector<int\> ?以前的优化方式是改成输入输出型参数

右值引用价值之一是补齐这个最后一个短板

右值引用价值之二是对于插入的数据可以减少拷贝



编译器优化：

1. 直接构造
2. 识别成右值，并调用移动拷贝或移动赋值



## 完美转发

为什么  ---  右值引用赋值后，又变成左值了

```c++
void func(int& n) { cout << "左值引用" << endl; }
void func(const int& n) { cout << "const左值引用" << endl; }
void func(int&& n) { cout << "右值引用" << endl; }
void func(const int&& n) { cout << "const右值引用" << endl; }


template<class T>
void PerfectForward(T&& t) // 万能引用
{
    // 这里既可能有左值有可能又右值
	//func(t);
	func(std::forward<T>(t)); // 完美转发 保持属性
}

int main()
{
	int n = 1;
	const int cn = 1;
	const int&& cr = 1;// 右值引用赋值之后cr又变为左值了

	PerfectForward(n); // 左值引用  T->int 引用折叠 整体是int&
	PerfectForward(cn); // const左值引用 T->const int 引用折叠 整体是const int&
	PerfectForward(1); // 右值引用 T->int 整体是int&&
	PerfectForward(cr); // const左值引用 T->const int 引用折叠 整体是const int&
    
    // 使用forward保留原来的属性
    PerfectForward(std::forward<const int>(cr)); // const右值引用 T->const int 整体是const int&&

	return 0;
}

```



怎么做到的

左值匹配，引用折叠

右值直接匹配
