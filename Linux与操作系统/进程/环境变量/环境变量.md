### 环境变量

#### 基本概念/是什么

* 环境变量（environment variables）一般是指在操作系统中用来指定操作系统运行环境的一些参数
* 如：我们在编写C/C++代码的时候，在链接的时候，从来不知道我们的所链接的动态静态库在哪里，但是照样可以链接成功，生成可执行程序，原因就是有相关环境变量帮助编译器进行查找
* 环境变量通常具有某些特殊用途，还有在系统当中通常具有全局特性



**为什么有这个东西，为什么设计成这样？具体结构实现？**



常见环境变量

* echo: 显示某个环境变量值
* export: 设置一个新的环境变量
* env: 显示所有环境变量
* unset: 清除环境变量
* set: 显示本地定义的shell变量和环境变量



测试PATH

1. 运行任意自己写的简单程序，为什么运行自己的程序时是`./test`而运行系统程序（指令）时并不需要带路径
2. 将测试程序所在路径加入环境变量PATH中，`export PATH=$PATH:hello`程序所在路径
3. 对比测试，此时运行自己的程序也不需要再带上路径
4. 还有什么方法可以不带路径，直接运行？
   * **将程序放入系统路径**（或者在这些路径创建**软硬链接**），也就是环境变量中PATH字段原有的那些路径中（当然，每个系统路径都有约定俗成的放置软件类型）
   * 使用别名`alias runmyapp='./a.out'`，这个方法只在当前shell会话有效，除非添加到shell配置文件中（如`.bashrc`或`.bash_profile`）
   * 添加配置（添加环境变量或者使用别名等）到shell配置文件`.bashrc`，这个配置文件的指令在每次新创建shell会话时都会执行一次





测试HOME

2. 执行`cd ~;pwd`和`echo $HOME`

结论：

* 不同用户环境变量有差异

环境变量的组织方式

每个进程都会收到一张环境变量表，环境变量表是一个字符指针数组，每个指针指向一个以`'\0'`为结尾的环境字符串



#### 通过代码获取环境变量

* 命令行第三个参数

  ```c
  #include <stdio.h>
  
  int main(int argc, char *argv[], char *env[])
  {                                              
      for(int i = 0;env[i];++i)
      {
        printf("%s\n", env[i]);
      }
  
      return 0;
  }
  ```

* 通过第三方变量`environ`获取

  ```c
  #include <stdio.h>
  
  int main()
  {
      extern char **environ;
      // libc中定义的全局变量environ指向环境变量表,environ没有包含在任何头文件中,所以在使用时 要用extern声明。 
      for(int i = 0;environ[i];++i)
      {                            
        printf("%s\n", environ[i]);
      }                  
                         
      return 0;          
  }                      
  ```



#### 通过系统调用获取或设置（指定）环境变量

* getenv

  ```c
  #include <stdio.h>                  
  #include <stdlib.h>
  
  int main()
  {
      printf("%s\n", getenv("PATH"));
      return 0;
  }
  ```

* putenv

  ```c
  // The  putenv()  function  adds  or  changes  the  value  of  environment variables. 
  // The argument string is of the form name=value.  
  // If name does not already exist in the environment, then string is added to the environment. 
  // If name does exist, then the value of name in the environment is changed to value.  
  // The string pointed to by string becomes part of the environment, so altering the string changes the environment.
  ```

  

#### 环境变量通常具有全局属性

可以被子进程继承下去

```c
#include <stdio.h>
#include <stdlib.h>

int main()
{
    char * env = getenv("MYENV");
    if(env) printf("%s\n", env);
    return 0;                        
}
```

1. 先运行此程序，没有打印出任何东西
2. 导出环境变量`export MYENV="hello world"  `
3. 再运行程序，发现打印出来了
4. 另外打开一个shell对话，运行此程序，没有打印出任何东西



**为什么？**

[Linux环境变量](https://creaink.github.io/post/Computer/Linux/Linux-env.html)

简单讲，环境变量存储在main函数栈帧之前，使用fork创建子进程会直接复制，而子进程里修改环境变量当然不会影响到父进程。而使用exec系列函数进行程序替换时，有的接口会提供传递环境变量的选项，没有提供的会自行传递现有进程的环境变量
